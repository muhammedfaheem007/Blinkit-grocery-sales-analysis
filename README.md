# 🛒 Blinkit Grocery Sales Analysis

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze Blinkit grocery sales data and identify key patterns in sales performance, outlet characteristics, and product categories.

The project focuses on transforming raw retail sales data into meaningful business insights through data cleaning, KPI reporting, data visualization, and interactive dashboard design.

---

## 🎯 Business Objective

The main objective of this project is to analyze grocery sales performance and answer questions such as:

- What are the overall sales and key performance indicators?
- Which product categories contribute most to sales?
- How does outlet size affect sales performance?
- How does outlet location influence sales?
- How does outlet establishment year relate to sales?
- Which product characteristics are associated with stronger sales performance?

## 📈 Key Analysis Areas

### Product Analysis
Sales performance was analyzed across different item types and product characteristics to identify important product-level trends.

### Outlet Analysis
The dashboard evaluates sales performance based on:

- Outlet Size
- Outlet Location
- Outlet Establishment Year

This helps understand how different store formats and locations contribute to overall sales.

### KPI Analysis
Key performance indicators are presented through an interactive Power BI dashboard to provide a quick overview of business performance.
